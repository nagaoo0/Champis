# AGARICS

genre *Agaricus*

## A - Chair nettement jaunissante à la base du pied (au grattage)

1. **Odeur d'amande amère ou d'anis à la base du pied**
   - **Anneau ample, persistant**
     - Jaunissement moyen ; pied élancé bulbeux à la base ; odeur anisée (d'amandes amères en vieillissant) à la base du pied ; dans les bois : ***Agaricus silvicola*** (agaric des bois) (2) ☺
     - Jaunissement faible ; pied robuste, non bulbeux à la base ; odeur anisée ; prairies et pâtures : ***Agaricus arvensis*** ("boules-de-neige") ☺
   - **Anneau simple, ténu** (vite disparu chez les adultes) ; petite espèce grêle à forte odeur d'amandes amères, dans les pelouses : ***Agaricus comtulus***
2. Odeur de phénol à la base du pied. Jaunissement rapide (rayure de l'ongle, coupe à la base du pied) ; silhouette trapézoïdale, pied nettement bulbeux ; pelouses, pâtures : ***Agaricus xanthodermus*** ☠ (agaric jaunissant) (1) - indigeste

## B - Chair rougissante, brunissante, ou immuable

- \* **Chair à rougissement vif**, rapide : ***Agaricus sylvaticus*** (agaric des forêts) ☺ (4)
- \* **Rougissement lent ou nul** :
  - Anneau simple, ténu (vite disparu chez l'adulte).
    - ° Base du pied arrondie ou atténuée, sans "racine". Dans les prés : ***Agaricus campestris*** (rosé-des-prés) ☺ (3)
    - ° Base du pied légèrement renflée, prolongée par une "racine" blanche. Parcs urbains, terre retournée : ***Agaricus bresadolanus*** ☠ (agaric radicant - indigeste) (5)
  - Anneau épais ou double, persistant chez les adultes.
    - ° Anneau simple.
      - Odeur fongique, chair lentement rougissante. Pelouses, prairies : ***Agaricus bisporus*** (champignon de Paris) ☺
      - Odeur terreuse désagréable. Chair immuable. Forêts, bords de sentiers, dunes : ***Agaricus variegans*** (agaric vergeté)
    - ° Anneau nettement dissocié en deux "étages" (la partie inférieure peut évoquer une volve)
      - Chapeau blanc : ***Agaricus bitorquis*** (agaric des trottoirs) ☺
      - Chapeau brun : ***Agaricus subperonatus*** (agaric des serres)

## Figures
